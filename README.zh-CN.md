# Elin's PEAK

**Languages:** [English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

## 让一切都能升级！

PEAK 本来就充满了糟糕的决定、惊险的攀爬、塞爆的背包、毒素、寒冷、高温、疲劳，以及那些完全可以避免的坠落。**Elin's PEAK 会让你的角色真正从这些经历中变强！**

核心思路很简单：**你反复做什么，就会逐渐擅长什么。** 负重移动会训练力量；持续攀爬会提升对应的攀爬技能；走路、冲刺、跳跃、从高处摔下来还活着、承受各种异常状态——这些实际经历都会转化为永久技能进度。

本模组受到 **Elin** 的使用式成长系统启发。没有一个万能的“角色等级”，也不需要在每局结束后分配通用技能点。技能会因为你真正使用了它们而成长！

当前版本加入 **18 个持久化技能**，默认最高等级为 **999**。进度属于你自己的玩家存档，保存在本地，并会跨会话保留，而不是由大厅房主决定。

## 可以升级什么？

### 身体能力
- **力量**：负重移动时获得经验。降低携带重量带来的 Weight，并在特定等级增加背包容量。
- **耐力**：消耗耐力时获得经验。提高真实最大耐力与耐力恢复速度。
- **运动能力**：走路与冲刺都会训练，冲刺更快。提高地面移动、冲刺移动以及冲刺耐力效率。
- **敏捷**：跳跃时训练。提高跳跃冲量、跳跃效率与少量空中操控。
- **体魄**：受到有效坠落伤害时训练。降低未来的坠落 Injury。

### 攀爬
- **攀岩**：提高墙面攀爬速度并降低耐力消耗。
- **绳索攀爬**：提高绳索攀爬速度与耐力效率。
- **藤蔓攀爬**：提高藤蔓攀爬速度、耐力效率，并保留更多移动惯性。
- **湿滑抓握**：在湿滑墙面攀爬时训练，降低湿滑下拉与相关耐力消耗。
- **攀爬韧性**：常规耐力低于 20% 时继续攀墙即可训练，降低低耐力下的控制、滑落和耐力惩罚。

### 抗性
蓝色的 **抗性** 面板包含八项独立成长：
**毒素、寒冷、高温、困倦、孢子、饥饿、诅咒、石化。**

这些技能只会在对应异常状态实际增加时获得经验。毒素、寒冷、高温、困倦和孢子还会提升游戏标记为“自然恢复”的恢复速度。诅咒与石化没有自然恢复计时器，因此只提供抗性。

## 力量也会扩展背包

力量除了减少 Weight，还会在里程碑等级为普通背包、腰包和喷气背包增加物品栏：

| 力量等级 | 额外背包格 |
|---:|---:|
| 20 | +1 |
| 40 | +2 |
| 70 | +3 |
| 120 | +4 |
| 200 | +5 |

主物品栏仍保持 PEAK 原版大小。Jet Pack 的燃料槽不会被修改，Rocket Pack 没有物品存储，因此被排除。

> 使用 Elin's PEAK 时应禁用 **BackpackCapacity**，因为两个模组都会修改同一份背包数据。

## 你的成长属于你

技能进度保存在本地。加入别人的大厅不会让房主覆盖你的技能等级。Airport/大厅中不会获得经验；自定义局的经验默认关闭，但可在配置中开启。

## 技能菜单与语言

技能会直接显示在暂停菜单中，包括等级、经验进度和当前效果说明。

模组界面会自动跟随 PEAK 中选择的语言，并在语言更改后立即刷新。未翻译的语言或缺少的翻译键会自动回退到英文。

# 技术细节

## 等级曲线
所有技能默认最高 999 级：
```text
XP(next) = round(100 * level^1.21)
```

## 默认经验来源
| 技能 | 默认经验来源 |
|---|---|
| 耐力 | 每 1 点归一化原始耐力请求 10 XP |
| 力量 | 每 1 原始 Weight × 移动米数 2 XP |
| 攀岩 / 绳索 / 藤蔓 | 每有效攀爬米数 8 XP |
| 运动能力 | 每有效步行米数 0.22 XP |
| 冲刺 | 每有效冲刺米数 1.05 XP |
| 敏捷 | 每次有效跳跃 8 XP |
| 体魄 | 每 1 点归一化原始坠落 Injury 100 XP |
| 抗性技能 | 每 1 点实际进入的对应异常状态 100 XP |
| 湿滑抓握 | 每湿滑攀爬米数 20 XP，并受湿滑程度加权 |
| 攀爬韧性 | 低于 20% 常规耐力时每攀墙米数 40 XP |

## 效果缩放
正向效果通常线性增长：耐力容量 +0.5%/级、耐力恢复 +0.1%/级、墙/绳/藤蔓速度 +0.3%/级、地面移动 +0.1%/级、额外冲刺移动 +0.2%/级、跳跃冲量 +0.15%/级、空中操控 +0.025%/级。

减伤/减耗类效果使用**锚定倒数曲线**，而不是无限线性相减。多数效果默认速率为 `0.003`，抗性使用 `0.0015`。曲线在 500 级后加速，并在 999 级逼近 **99.9% 减免**。

## 存档
```text
%LOCALAPPDATA%\LandCrab\PEAK\PEAKUsageSkills\progression.json
```
采用安全/原子写入，并保留 5 个轮换备份。
