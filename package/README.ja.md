# Elin's PEAK

**Languages:** [English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

## 何でもレベルアップ！

PEAK には、無茶な判断、命がけの登攀、詰め込みすぎたバックパック、毒、寒さ、暑さ、疲労、そして避けられたはずの落下事故が山ほどあります。**Elin's PEAK では、その全部からキャラクターが本当に成長します！**

考え方は単純です。**使い続けた能力ほど上達する。** 重い荷物を運べば筋力が伸び、登り続ければ登攀能力が伸び、走る・跳ぶ・落下に耐える・状態異常を受けるといった実際のプレイが恒久的な進行になります。

**Elin** の使用ベース成長に強く影響を受けています。万能のキャラクターレベルや、ラン終了後に配る汎用ポイントはありません。スキルは実際に使ったから上がります！

現在は **18種類の永続スキル** があり、既定の最大レベルは **999**。進行はプレイヤーごとにローカル保存され、セッションをまたいで維持されます。

## 育つ能力

### 基礎能力
- **筋力**：Weightを持って移動すると成長。持ち運びのWeightを軽減し、節目のレベルでバックパック容量を増やします。
- **持久力**：スタミナ消費で成長。実際の最大スタミナと回復速度を増加。
- **運動能力**：歩行とダッシュで成長。地上移動、ダッシュ移動、ダッシュ効率を改善。
- **敏捷性**：ジャンプで成長。ジャンプ力、ジャンプ効率、わずかな空中操作を改善。
- **生命力**：有効な落下ダメージを受けると成長。以後の落下 Injury を軽減。

### 登攀
- **壁登り**：壁の登攀速度とスタミナ効率を改善。
- **ロープ登り**：ロープの速度と効率を改善。
- **つる登り**：つるの速度、効率、移動の勢いを改善。
- **ウェットグリップ**：滑りやすい壁で成長し、下向きの引力と関連スタミナ消費を軽減。
- **登攀粘り強さ**：通常スタミナ20%未満で壁を登り続けると成長し、低スタミナ時の操作・滑落・消費ペナルティを軽減。

### 耐性
青い **耐性** パネルには、**毒、寒さ、暑さ、眠気、胞子、空腹、呪い、石化** の8スキルがあります。

対応する状態異常が実際に増加したときだけXPを獲得します。毒・寒さ・暑さ・眠気・胞子は、PEAK側で自然回復として扱われる経路の回復速度も改善します。

## 筋力でバックパックも成長

| 筋力レベル | 追加バックパック枠 |
|---:|---:|
| 20 | +1 |
| 40 | +2 |
| 70 | +3 |
| 120 | +4 |
| 200 | +5 |

メインインベントリはバニラのままです。通常バックパック、ファニーパック、ジェットパックに同じ節目ボーナスが適用されます。Jet Packの燃料スロットは変更しません。

> **BackpackCapacity** は同じバックパックデータを変更するため、Elin's PEAK と同時使用しないでください。

## プレイヤー所有の進行
進行はローカル保存です。他人のロビーに参加してもホストがあなたのレベルを上書きすることはありません。Airport/ロビーではXPを獲得できません。カスタムランのXPは既定で無効です。

## スキルメニューと言語
一時停止メニューにスキル名、レベル、進行度、現在の効果説明を表示します。

Mod の UI は PEAK で選択した言語に自動で従い、言語を変更するとすぐに更新されます。未翻訳の言語やキーは自動的に英語へフォールバックします。

# 技術情報

## XP曲線
```text
XP(next) = round(100 * level^1.21)
```
既定最大レベルは999です。

## 既定XP
| スキル | XP |
|---|---|
| 持久力 | 正規化された生スタミナ要求1点につき10 XP |
| 筋力 | 生Weight × 移動1mにつき2 XP |
| 壁/ロープ/つる | 有効な登攀1mにつき8 XP |
| 歩行 | 1mにつき0.22 XP |
| ダッシュ | 1mにつき1.05 XP |
| 敏捷性 | 有効ジャンプ1回につき8 XP |
| 生命力 | 正規化された落下 Injury 1点につき100 XP |
| 耐性 | 実際に増加した対応状態1点につき100 XP |
| ウェットグリップ | 滑りやすい登攀1mにつき20 XP（滑りやすさで加重） |
| 登攀粘り強さ | 通常スタミナ20%未満で壁登り1mにつき40 XP |

## 効果
正の効果は基本的に線形です。最大スタミナ+0.5%/Lv、回復+0.1%/Lv、各登攀速度+0.3%/Lv、地上移動+0.1%/Lv、追加ダッシュ+0.2%/Lv、ジャンプ+0.15%/Lv、空中操作+0.025%/Lv。

軽減系は線形減算ではなく**アンカー付き逆数曲線**を使い、999レベルで **99.9%軽減**へ近づきます。

## セーブ
```text
%LOCALAPPDATA%\LandCrab\PEAK\PEAKUsageSkills\progression.json
```
安全な原子的書き込みと5世代のバックアップを使用します。
