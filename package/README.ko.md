# Elin's PEAK

**Languages:** [English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

## 모든 것을 레벨업하세요!

PEAK에는 위험한 등반, 과적된 가방, 독, 추위, 더위, 피로, 그리고 충분히 피할 수 있었던 추락이 가득합니다. **Elin's PEAK에서는 캐릭터가 그 모든 경험을 통해 실제로 성장합니다!**

원리는 간단합니다. **계속 사용하는 능력은 점점 좋아집니다.** 무거운 짐을 들고 이동하면 힘이 오르고, 계속 오르면 등반 능력이 오르며, 걷고 달리고 뛰고 추락에서 살아남고 상태 이상을 버티는 실제 플레이가 영구적인 성장으로 바뀝니다.

**Elin**의 사용 기반 성장 시스템에서 크게 영감을 받았습니다. 하나의 만능 캐릭터 레벨이나 런 종료 후 배분하는 공용 포인트는 없습니다. 실제로 사용한 스킬이 성장합니다!

현재 **18개의 영구 스킬**이 있으며 기본 최대 레벨은 **999**입니다. 진행도는 플레이어 로컬 저장이며 세션 사이에도 유지됩니다.

## 어떤 스킬이 성장하나요?

### 기본 능력
- **힘**: Weight를 들고 이동하면 성장합니다. 운반 Weight를 줄이고 특정 레벨에서 가방 슬롯을 추가합니다.
- **지구력**: 스태미나를 사용하면 성장합니다. 실제 최대 스태미나와 재생 속도를 높입니다.
- **운동 능력**: 걷기와 달리기로 성장합니다. 지상 이동, 달리기 이동, 달리기 효율을 높입니다.
- **민첩성**: 점프로 성장합니다. 점프 힘, 점프 효율, 약간의 공중 제어를 높입니다.
- **생명력**: 정상적인 낙하 부상을 받으면 성장하며 이후 낙하 Injury를 줄입니다.

### 등반
- **벽 등반**: 벽 등반 속도와 스태미나 효율을 향상합니다.
- **로프 등반**: 로프 속도와 효율을 향상합니다.
- **덩굴 등반**: 덩굴 속도, 효율, 운동량 유지력을 향상합니다.
- **젖은 표면 그립**: 미끄러운 벽을 오를 때 성장하며 아래쪽 끌림과 관련 스태미나 소모를 줄입니다.
- **등반 투지**: 일반 스태미나가 20% 미만일 때 계속 벽을 오르면 성장하며 저스태미나 등반 페널티를 줄입니다.

### 내성
파란 **내성** 패널에는 **독, 추위, 더위, 졸림, 포자, 배고픔, 저주, 석화**가 있습니다.

해당 상태 이상이 실제로 증가할 때만 XP를 얻습니다. 독/추위/더위/졸림/포자는 PEAK가 자연 회복으로 표시하는 경로의 회복 속도도 높입니다.

## 힘이 오르면 가방도 커집니다

| 힘 레벨 | 추가 가방 슬롯 |
|---:|---:|
| 20 | +1 |
| 40 | +2 |
| 70 | +3 |
| 120 | +4 |
| 200 | +5 |

메인 인벤토리는 바닐라 크기를 유지합니다. 일반 백팩, 패니 팩, 제트 팩에 동일한 마일스톤이 적용됩니다. Jet Pack 연료 슬롯은 건드리지 않습니다.

> **BackpackCapacity**는 같은 가방 데이터를 수정하므로 함께 사용하지 마세요.

## 진행도는 플레이어 소유
진행도는 로컬에 저장됩니다. 다른 사람의 로비에 들어가도 호스트가 레벨을 덮어쓰지 않습니다. Airport/로비에서는 XP를 얻지 않으며 커스텀 런 XP는 기본적으로 꺼져 있습니다.

## 스킬 메뉴 및 언어
일시정지 메뉴에서 스킬 이름, 레벨, 진행도, 현재 효과를 볼 수 있습니다.

모드 UI는 PEAK에서 선택한 언어를 자동으로 따르며 언어를 변경하면 즉시 갱신됩니다. 번역되지 않은 언어나 키는 영어로 자동 대체됩니다.

# 기술 정보

## XP 곡선
```text
XP(next) = round(100 * level^1.21)
```
기본 최대 레벨은 999입니다.

## 기본 XP
| 스킬 | 기본 획득량 |
|---|---|
| 지구력 | 정규화된 원시 스태미나 요청 1당 10 XP |
| 힘 | 원시 Weight × 이동 1m당 2 XP |
| 벽/로프/덩굴 | 유효 등반 1m당 8 XP |
| 걷기 | 1m당 0.22 XP |
| 달리기 | 1m당 1.05 XP |
| 민첩성 | 유효 점프 1회당 8 XP |
| 생명력 | 정규화된 낙하 Injury 1당 100 XP |
| 내성 | 실제로 적용된 해당 상태 1당 100 XP |
| 젖은 표면 그립 | 미끄러운 등반 1m당 20 XP, 미끄러움 가중 |
| 등반 투지 | 일반 스태미나 20% 미만에서 벽 등반 1m당 40 XP |

## 효과
양의 보너스는 주로 선형입니다: 최대 스태미나 +0.5%/레벨, 재생 +0.1%, 등반 속도 +0.3%, 지상 이동 +0.1%, 추가 달리기 +0.2%, 점프 +0.15%, 공중 제어 +0.025%.

감소 계열은 단순 선형 차감이 아니라 **앵커 역수 곡선**을 사용하며 999레벨에서 **99.9% 감소**에 접근합니다.
